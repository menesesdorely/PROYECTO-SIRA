# SIRA – Sistema de Información para la Relación y Activación Laboral

**Diseño y validación de un prototipo para la intermediación laboral de trabajadores independientes en Popayán, Cauca.**

## Descripción del Proyecto
SIRA es una plataforma digital diseñada para facilitar el contacto directo entre trabajadores independientes y empresas o personas contratantes en la ciudad de Popayán, Cauca. El proyecto busca resolver la dispersión de ofertas laborales, la dificultad para verificar perfiles y la dependencia de recomendaciones informales, centralizando perfiles profesionales, publicación de microempleos, filtros de búsqueda y un sistema de calificación recíproca.

## Objetivo General
Diseñar y validar un prototipo de alta fidelidad de la plataforma SIRA mediante el análisis de necesidades, el diseño de interfaces y las pruebas de usabilidad, para facilitar la conexión entre trabajadores independientes y potenciales contratantes en la ciudad de Popayán.

## Instrucciones de Uso del Prototipo (Figma)
El prototipo interactivo de alta fidelidad fue desarrollado en **Figma** bajo el marco ágil Scrum y los principios de usabilidad ISO 9241-11.

* **Enlace al prototipo interactivo:** [Ver prototipo SIRA en Figma](https://www.figma.com/design/we02fjUe6ygKBMuFtzZG9N/SIRA?node-id=0-1&p=f&t=1RylxUq1OXkhmQ6l-0)

**Flujos principales disponibles para navegación:**
1. **Acceso y Registro:** Pantalla de inicio con selección de rol (*Trabajador* con validación de cédula o *Empresa* con validación de NIT) y aceptación de tratamiento de datos.
2. **Rol Trabajador:** Consulta de perfil (habilidades, certificaciones y reseñas), búsqueda de vacantes con filtros y seguimiento del estado de postulaciones.
3. **Rol Empresa:** Panel de gestión de vacantes publicadas, revisión de postulantes, búsqueda en directorio y calificación de servicios.
